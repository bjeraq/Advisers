# صائد المظلومات

الهدف: قائمة قصيرة بأسهم متوافقة شرعياً، شركاتها قوية (هوامش وعوائد
مرتفعة وديون خفيفة)، هبطت بحدة لسبب يبدو عابراً (إشاعة، خبر سياسي، ذعر
قطاع) لا لتدهور حقيقي — مع الدليل الإخباري لكل ترشيح.

## الخطوات

1. اسحب السوق ورشّح آلياً:

   ```bash
   python3 -m advisers.quotes --out <سكراتش>/scan.json
   python3 -m advisers.bargains --rows <سكراتش>/scan.json --top 8
   ```

2. **التحقيق الإخباري — جوهر المهمة.** لكل مرشح اجلب أخبار آخر ١٤ يوماً:

   ```bash
   python3 -m advisers.newswatch --symbol TICKER --minutes 20160
   ```

   اقرأ العناوين وصنّف سبب الهبوط:
   - **مظلوم محتمل:** السبب أخبار سياسية/تنظيمية عامة، إشاعة، مخاوف
     تعريفات، هبوط قطاع كامل، تصريح متداول — ولا يوجد خلل في نتائج
     الشركة نفسها.
   - **مستبعد:** نتائج فعلية سيئة، خفض توجيهات، تحقيق جوهري في الشركة
     ذاتها، مشكلة منتج حقيقية — احذفه من التقرير.
   - **غير واضح:** أبقه معلّماً بذلك بصراحة.

3. **التقرير:** رسالة تيليجرام عربية بقالب واضح: لكل سهم — الرمز، نسبة
   الهبوط، سطر الجودة (من `why_ar`)، سبب الهبوط الذي وجدته بالأخبار مع
   اسم المصدر، وتصنيفك (مظلوم محتمل / غير واضح). اختم بتذكير: انكشاف
   الإشاعة غير مضمون ولا موقوت، وهذه معلومات لا توصية. أرسلها بـ:

   ```bash
   python3 -m advisers.telegram --send-file <ملف الرسالة>
   ```

   (لو `TELEGRAM_BOT_TOKEN` غير موجود: اعرض الرسالة في ردك النهائي بدل الإرسال.)

4. احفظ نسخة كاملة في `reports/mazloum_<YYYY-MM-DD>.md` واعمل commit
   و push للفرع `claude/vibrant-mayer-mu1ifg`.

5. لو ما طلع أي مرشح بعد الفرز: أرسل سطراً واحداً «ما لقيت مظلومين هذا
   الأسبوع» — ولا تخترع مرشحين ضعافاً لتعبئة التقرير.

## قواعد

- لا أوامر تداول؛ والقرار للمستخدم.
- كل سبب هبوط يُنسب لعنوان خبر حقيقي من الجلب أعلاه — ممنوع التخمين بلا مصدر.
- العربية في الرسالة والتقرير.
