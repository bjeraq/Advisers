# راصد الصباح

الهدف: رسالة تيليجرام واحدة فيها أعلى ٥ رابحين و٥ خاسرين من الأسهم المتوافقة
(من واقع `data/universe_us.csv`)، خلال أول ربع ساعة من افتتاح السوق الأمريكي.

## الخطوات

0. **فحص التوكن:** إذا متغير البيئة `TELEGRAM_BOT_TOKEN` غير موجود، لا تكمل:
   ردّك النهائي يوضح أن التوكن ناقص وأن المستخدم يضيفه من إعدادات البيئة
   (قائمة البيئة في شريط عنوان الجلسة ← تعديل ← متغيرات البيئة).

1. من داخل مجلد المستودع، اسحب الأسعار الحية إلى ملف مؤقت في مجلد
   السكراتش باد الخاص بجلستك (سمه `scan.json`):

   ```bash
   python3 -m advisers.quotes --out <مسار-السكراتش-باد>/scan.json
   ```

   لو فشل السحب، أعد المحاولة مرة ثانية بعد ٣٠ ثانية.

2. **اكتشاف معرف القروب (حين لا يكون محفوظاً):** إذا ما فيه متغير
   `TELEGRAM_CHAT_ID` ولا ملف `config/telegram.json`:

   ```bash
   python3 -m advisers.telegram --discover
   ```

   - لو ظهرت محادثة واحدة اسمها يحتوي «انفست» أو «Invest» أو «Portfolio»:
     اكتب `{"chat_id": "<المعرف>"}` في `config/telegram.json` **محلياً فقط**
     (الجلسات المجدولة لا تستطيع الدفع للمستودع — لا تحاول commit)، ثم
     أرسل للقروب نفسه رسالة تمكين دائمة، مع استبدال المعرف الحقيقي:

     ```bash
     python3 -m advisers.telegram --send "🔧 لتثبيت الربط نهائياً: أضف في نافذة متغيرات البيئة سطراً ثانياً هو TELEGRAM_CHAT_ID=<المعرف> ثم احفظ."
     ```

   - لو ما ظهرت أي محادثة أو ظهرت أكثر من وحدة مناسبة: اشرح الوضع في ردك
     النهائي (البوت ليس عضواً في القروب، أو لا رسالة حديثة فيه) ولا تكمل.

3. أرسل رسالة الصباح (القائمة الشرعية تُحسب طازجة من بيانات اليوم):

   ```bash
   python3 -m advisers.scout --rows <مسار-السكراتش-باد>/scan.json --fresh-universe --send
   ```

   الأمر يتخطى أيام العطل تلقائياً — لا تستخدم `--force` في التشغيل المجدول.

4. لو فشلت الخطوة ١ نهائياً (بعد إعادة المحاولة)، أرسل اعتذاراً بدل الصمت:

   ```bash
   python3 -m advisers.scout --send --fail-reason "تعذر سحب بيانات الأسعار"
   ```

## قواعد

- لا تنفذ أي أوامر تداول أو شراء أو بيع إطلاقاً — هذه مهمة إخبارية فقط.
- لا تعدل أي ملف غير `config/telegram.json` محلياً (وفي حالتها فقط)،
  ولا تحاول commit أو push — الجلسات المجدولة لا تملك صلاحية الدفع.
- ردك النهائي سطر أو سطران بالعربي: وش صار وهل وصلت الرسالة.

## تحديث صفحة النتائج (بعد نجاح الإرسال)

اقرأ الرابط من `config/results_artifact.json`، ثم اقرأ الأرتيفاكت بأداة
الأرتيفاكت (action: read مع url). استبدل كامل ما بين السطرين
`<!--DATA:morning:start-->` و `<!--DATA:morning:end-->` بنفس بنية اللوحتين
(رابحون/خاسرون) ببيانات اليوم، وحدّث ما بين علامتي `DATA:updated` بتاريخ
اليوم، وانشر بنفس الـ url. لو تعذرت القراءة أو النشر تجاوز الخطوة بصمت —
رسالة تيليجرام هي الأساس.
