# الجريدة الموثّقة (Advisers)

جريدة إلكترونية ثابتة (HTML) تلخّص الأخبار من مصادر متعددة مع بيان درجة التأكد من كل معلومة.

- `site/` : الموقع (الصفحة الرئيسية، الملفات المعمّقة، المنهجية)
- `.github/workflows/pages.yml` : النشر على GitHub Pages عند الدمج في `main`

## النشر
من إعدادات المستودع: Settings ← Pages ← Source: **GitHub Actions**. بعد دمج الفرع في `main` يظهر الموقع على `https://<user>.github.io/Advisers/`.

للمعاينة محلياً: افتح `site/index.html` في المتصفح.
